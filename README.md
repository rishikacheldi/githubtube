# 📊 Amazon India Sales Analysis Dashboard

## 📌 Project Overview

The **Amazon India Sales Analysis Dashboard** is an interactive Power BI project designed to analyze sales performance, profitability, product categories, order status, payment methods, fulfillment channels, and geographical sales distribution.

The dashboard transforms raw sales data into meaningful visualizations and key performance indicators (KPIs), helping stakeholders understand business performance, identify trends, and make data-driven decisions.

## 🎯 Objectives

- Analyze overall sales and revenue performance.
- Evaluate product and category-wise sales.
- Understand order status and fulfillment performance.
- Examine customer payment method preferences.
- Identify geographical sales patterns across India.
- Present key business insights through interactive visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization.
- **Microsoft Excel** — Dataset storage and data preparation.
- **Power Query** — Data cleaning and transformation.
- **DAX** — Calculated measures and KPIs.

## 📈 Dashboard Features

- **Sales Performance:** Explore overall sales and revenue trends.
- **Product Analysis:** Compare sales across products and categories.
- **Order Status:** Analyze order distribution and fulfillment outcomes.
- **Payment Analysis:** Understand the distribution of payment methods.
- **Geographical Analysis:** Examine sales performance across different locations.
- **Interactive Reporting:** Use Power BI filters and visualizations to explore the data.

## 🚀 Getting Started

### Prerequisites

- Microsoft Power BI Desktop.
- Microsoft Excel or a compatible spreadsheet application.

### Installation and Usage

1. Clone or download this repository.
2. Locate the `Amazon Sales Data India.xlsx` dataset.
3. Open `Amazon_indian_sales_dashboard.pbix` using Power BI Desktop.
4. If prompted, update the dataset file path in the data source settings.
5. Refresh the data if required.
6. Explore the dashboard using its interactive visuals and filters.
